2. 45° 축 회전 행렬 변환 과정
1원래 이차곡선의 행렬 표현
이차형식 대칭행렬 Q와 일차항 행벡터 K로 방정식을 행렬 형태로 나타냅니다.
2θ = 45° 회전 변환 행렬 정의
좌표축을 반시계 방향으로 45° 회전하는 직교행렬 R (R⁻¹ = Rᵀ)을 정의합니다.
3직교변환을 통한 새로운 행렬 계산 (Q' = RᵀQR, K' = KR)
x = Rx' 을 대입하면 x'ᵀ(RᵀQR)x' + (KR)x' + F = 0 이 됩니다.
4변환된 최종 이차곡선 방정식 도출
계산된 Q'과 K'의 성분으로부터 회전 좌표계 (x', y')에서의 방정식을 얻습니다.
